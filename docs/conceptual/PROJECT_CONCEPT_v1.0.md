# Balangkas: accessible esports competition and identity

Balangkas means a framework: a connected environment for grassroots and collegiate teams to organize competitions, keep match history and recognize achievement. It reduces dependence on scattered chats, spreadsheets and unverifiable reward claims.

| Audience | Outcome |
| --- | --- |
| Players | Build a profile, declare school affiliation, join squads and retain a career portfolio. |
| Captains/coaches | Coordinate lineups, find scrimmages and inspect historical performance. |
| Communities | Organize members, teams, posts, competition activity and exports. |
| Tournament staff | Configure eligibility/brackets, review evidence and recognize recipients. |
| Visitors/judges | Discover events, inspect permitted profiles and verify issued credentials. |

Journey: establish identity -> join community/team -> register or find scrimmage -> play -> submit/review result -> inspect history -> recognize achievement.

All twelve modules in [requirements](../FRS_NFRS.md) remain required. [Screen specifications](../screens/README.md) preserve the finalized frontend. External demonstrations and deployed artifacts do not establish PCC completion.

Accessible infrastructure supports SDG 9, equitable grassroots participation supports SDG 10, and auditable operations supports SDG 16. These are motivations, not measured impact claims. Biometrics reduces duplicate-identity risk; it does not guarantee elimination of cheating.

One Next.js client and one Azure VPS host the application. External integrations remain external. Before onsite, only documentation, infrastructure configuration, dependencies and approved assets exist.
