# 30: identity, fair play and reward safety

Use authenticated session principal for ownership. Never generate acting-user IDs, accept client ownership fields, substitute random face vectors or report verified when inference/dependencies fail. The frontend's version-pinned `@vladmandic/human` owns detection, multiple-face rejection, alignment, cropping and the browser blink/liveness/anti-spoof gate; backend biometric inference does not repeat face detection or counting. Biometric inference uses only the documented, SHA-256-verified local W600K-R50 artifact; a missing/mismatched artifact, missing InsightFace-use approval, missing approved Human browser assets or failed capture gate is unavailable, never a fallback. The embedding model is not a liveness detector. Human's browser result is a hackathon capture gate, not cryptographic or server-verifiable proof, so the API must bind a single-use liveness challenge to the session/action/crop digest and never claim more than it can verify. Retain the normalized embedding only after consent, a consumed challenge and serialized exact duplicate comparison; discard raw frames and the client report.

Wallet linking requires a signed **Solana Devnet** challenge with exact user/address/origin/purpose binding and separate biometric authorization. Monetary values are exact centavos/lamports. Chain evidence is a configured-genesis, successful finalized Devnet read: browser callbacks never settle; the worker-only signer never reaches API/frontend. Payout/issuance requires verified evidence, authorized release and idempotency. PayMongo is test-mode Hosted Checkout for entry-fee simulation only: never use a live key/event or create a Wallet, recipient, payout, transfer, InstaPay/PESONet or refund operation during this hackathon. A user certificate recipient needs a linked wallet; a team uses separate explicit system custody. Official certificates are Metaplex Core NFT assets with a server-owned public-metadata allowlist, `PermanentFreezeDelegate(frozen: true, authority: None)`, no update authority and no collection claim; an ambiguous issuance is reconciled without another signer action.
