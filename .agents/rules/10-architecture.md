# 10: architecture

The target is one public origin on one Azure VPS: Nginx routes application paths to Next.js and `/api/`/`/ws/` to FastAPI. PostgreSQL/pgvector, Redis, MinIO and worker stay in the private Compose network. Ports other than Nginx remain private on the VPS.

PostgreSQL is canonical durable state. Redis is transient throttle/cache/pub-sub, not authority. MinIO holds authorized objects; raw biometrics are not retained. The version-pinned frontend `@vladmandic/human` capture pipeline detects/rejects face counts, aligns a crop, and performs the browser blink/liveness/anti-spoof gate; the biometric API does not repeat browser face detection or counting. It may read only the SHA-256-verified local W600K-R50 embedding artifact from its read-only model mount; it is never a Git, image, browser or object-store asset. Worker side effects begin from durable jobs/outbox records. See [architecture](../../docs/ARCHITECTURE.md), [backend structure](../../docs/BACKEND_STRUCTURE.md), [browser/API integration](../../docs/API_INTEGRATION.md), [configuration](../../docs/CONFIGURATION.md), [face-model record](../../docs/FACE_RECOGNITION_MODEL.md), [storage/jobs](../../docs/STORAGE_JOBS.md) and [data](../../docs/DATABASE.md).

There is one connected frontend, not a disconnected showcase. Preserve the approved visual/interaction baseline in [screens](../../docs/screens/README.md). Do not treat client-local state from an external reference as a server contract.
