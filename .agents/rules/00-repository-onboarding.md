# 00: onboarding and preparation gate

Read [AGENTS.md](../../AGENTS.md), this numbered rule set, [preparation boundary](../../docs/PREPARATION.md), [documentation index](../../docs/README.md), [architecture](../../docs/ARCHITECTURE.md), [requirements](../../docs/FRS_NFRS.md), and relevant feature/screen contracts before changing this repository.

During PREPARATION, only documentation, approved assets/reference data, dependencies, infrastructure configuration and empty folder markers may be added. Do not create application source, models, schemas, migrations, seeders, tests, smart contracts, generated clients or framework scaffolding. An explicit onsite instruction is the only unlock.

Inspect Git status once Git is initialized. Preserve user work. Use relative repository paths in Markdown and comments.
